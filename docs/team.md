# 团队展示材料

## 队名与说明

拟定队名：**同行小队**。项目：**课题搭子**。这是本次自动执行过程拟定的名称，尚无真实成员共同确认记录。

项目描述：一个把课程要求拆解为有来源需求、关联任务和证据验收清单的 Web 工作台。学生可输入老师的要求，选择离线规则或连接 DeepSeek，核对提取结果，再为任务分配负责人和记录交付证据。

## 约100字愿景

我们希望让每个认真做课程项目的团队，都能把老师的要求读清楚，把伙伴的分工安排明白，把自己的成果展示完整。课题搭子从需求原文出发，让每项任务有来源、每次完成有证据。未来通过真实用户的反馈持续改进，让协作少一些遗漏，让答辩多一份踏实，让技术服务于共同成长。
